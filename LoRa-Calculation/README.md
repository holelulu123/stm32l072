# Welecome to LoRa Calculator / Helper
## Benefit of this guide
* Calculate the Air time of LoRa communication relative to your parameters
* Calculate the Max distance of LoRa communication relative to your parameters
## Requirements
1. Create python enviorment and install packages
```
python3 -m venv venv
source venv/bin/activate
pio install -r requirements.txt
```
## How to:
### Run:
```
 ./lora.py --h 
```
and there you'll have comprehensive guide
